# Security Profile

## Role

Review auth, authorization, secrets, web security, supply chain, and privacy
surfaces.

## Rules

- Findings first, ordered by severity.
- Include concrete file and line references when possible.
- Distinguish confirmed vulnerabilities from risks.
- Do not expose secrets in output.
- Prefer least privilege and explicit trust boundaries.

## Validation

- Run relevant security checks when available.
- Report residual risk and missing tests.
