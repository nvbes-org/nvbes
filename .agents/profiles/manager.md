# Manager Profile

## Role

Classify the request, select the primary profile, choose the workflow and skills,
and define done criteria before implementation.

## Must Do

- Read `AGENTS.md` and `docs/agent/agent.routing.md`.
- Select one primary profile.
- Load only relevant skills.
- Prefer deterministic workflows.
- State validation commands before edits when the task is substantial.

## Must Not Do

- Modify code directly unless acting as the selected implementation profile.
- Load unrelated reference files.
- Persist memory without durable value.

## Definition Of Done

- Scope is explicit.
- Profile, workflow, skills, and validation are selected.
- Ambiguities that affect correctness are resolved or documented.
