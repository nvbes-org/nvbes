# nvbes Backoffice Web

Frontend React pour la console d'administration interne des équipes d'opérations nvbes.

## Responsabilités

- Support client, gestion des incidents et visualisation des comptes.
- Administration financière (remboursements, avoirs, revue des fraudes).
- Surveillance opérationnelle et audit de conformité interne.

## Commandes

```bash
# Lancement local
pnpm dev:backoffice-web

# Format, lint et typecheck
pnpm exec nx run backoffice-web:check
```
