# Documents juridiques

Les fichiers de ce dossier sont des projets de documents destinés aux services
nvbes concernés. Leur présence dans le dépôt public documente le travail en
cours ; elle ne vaut ni publication sur un service, ni acceptation par un
utilisateur, ni entrée en vigueur.

Un document n'est publiable que lorsqu'il ne contient plus de marqueur
`[À COMPLÉTER]` ou `[À CONFIRMER]`, qu'il correspond aux traitements et
prestataires réellement déployés, et qu'une date d'entrée en vigueur a été
validée. Les annexes contractuelles peuvent conserver des champs à compléter
par les parties lorsqu'elles sont explicitement présentées comme modèles.

La politique de licence du code source est distincte de ces documents et se
trouve dans [`open-source-licensing.md`](open-source-licensing.md).
