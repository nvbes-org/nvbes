# nvbes Console Web

Frontend React pour le Developer Portal / Console Développeur nvbes.

## Responsabilités

- Gestion des applications OAuth, clés d'API et webhooks.
- Visualisation des journaux d'appels et métriques d'usage API.
- Documentation interactive des API publiques nvbes.

## Commandes

```bash
# Lancement local
pnpm dev:console-web

# Format, lint et typecheck
pnpm exec nx run console-web:check
```
