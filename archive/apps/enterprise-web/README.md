# nvbes Enterprise Web

Frontend React pour la console d'administration Entreprise.

## Responsabilités

- Interface pour les administrateurs d'organisations et d'entreprises.
- Configuration du SSO d'entreprise (SAML, OIDC), provisioning SCIM et politiques MFA.
- Visualisation des journaux d'audit d'entreprise et gestion des membres.

## Commandes

```bash
# Lancement local
pnpm dev:enterprise-web

# Format, lint et typecheck
pnpm exec nx run enterprise-web:check
```
