## Commandes Clés au Quotidien

```bash
# Démarrer l'infrastructure et les services
pnpm dev:infra
pnpm dev:api
pnpm dev:web

# Synchroniser la documentation et réparer toute dérive
pnpm doc:fix

# Lancer la validation complète avant commit
pnpm check
```
