Every enterprise-web request carries tenant context. Workspace context is optional and only used when editing a workspace-scoped resource.

V0 API stance

Build tenant-level read models for the console first: enterprise overview, users, invitations, workspace access, and policy summaries. Reuse existing workspace endpoints only behind enterprise-web adapters where the action is truly workspace-scoped.
