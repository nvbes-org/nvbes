# Security & Compliance Tooling

Suite de 16 garde-fous automatisés pour la sécurité applicative, la gestion des secrets, l'analyse de dépendances et la conformité.

## Commandes

```bash
# Exécution complète de la suite sécurité
pnpm check:security

# Scan des secrets
pnpm check:secrets

# Validation SBOM
pnpm check:sbom
```
