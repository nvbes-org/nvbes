# @nvbes/web-runtime

Runtime frontend partagé pour les applications React de l'écosystème nvbes.

## Fonctionnalités

- Configuration standardisée de TanStack Query (React Query) et mise en cache.
- Gestion centralisée des contextes d'authentification, de navigation et d'erreurs.
- Intégration d'Effect et utilitaires fonctionnels pour la gestion d'état.
