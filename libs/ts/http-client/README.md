# @nvbes/http-client

Client HTTP TypeScript résilient, typé et validé à l'exécution pour les frontends et SDKs nvbes.

## Fonctionnalités

- Gestion automatique de la propagation des identifiants de corrélation (`x-request-id`).
- Gestion des erreurs HTTP structurées et typées sans `any`.
- Support des intercepteurs d'authentification et de rafraîchissement de jetons.
