# Rust Cloud Adapters

Target location for managed Cloud provider adapters such as Stripe, R2, hosted KYC and managed email.

Implemented Cloud adapters:

- `analytics-posthog`: PostHog product analytics implementation of `nvbes-product-analytics`.
- `email-scaleway`: Scaleway Transactional Email implementation of `nvbes-email`.

This area is Cloud-only and must not be exported to `nvbes-oss`.
