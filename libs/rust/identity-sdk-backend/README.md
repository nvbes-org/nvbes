# nvbes Identity SDK (Backend)

SDK Rust pour l'intégration et la validation des jetons d'accès émis par nvbes Identity.

## Fonctionnalités

- Vérification locale des JWT via les clés publiques JWKS d'Identity.
- Validation stricte des audiences et des scopes par ressource.
- Introspection centrale des tokens pour les contextes à haute sécurité.
