# nvbes Email Scaleway Adapter

Adaptateur Rust implémentant l'envoi d'emails transactionnels via le service Scaleway Transactional Email (TEM).

## Fonctionnalités

- Authentification via clé API Scaleway (`SCW_SECRET_KEY`).
- Envoi d'emails formatés MIME avec pièces jointes et suivi des statuts de livraison.
