# nvbes Audit

Primitives d'audit append-only pour la traçabilité des opérations sensibles sur la plateforme nvbes.

## Fonctionnalités

- Enregistrement immuable des événements d'audit (connexions, modifications de rôle, accès fichiers).
- Traçabilité des acteurs, des adresses IP et des contextes de requêtes.
- Structure optimisée pour les requêtes de conformité et de reporting.
