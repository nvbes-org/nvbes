# nvbes Core

Primitives et utilitaires de base partagés par l'ensemble des services backend Rust.

## Fonctionnalités

- Chargement typé des variables d'environnement (`Config`).
- Structures d'erreurs HTTP standard (`HttpError`) et contrats d'erreurs de domaine.
- Primitives d'idempotence et gestion de requêtes sécurisées.
